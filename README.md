Alexandria Biblioteca

Sistema de biblioteca em Python.

Como rodar:

python main.py

Estrutura

- main.py: Execução do sistema
- menu.py: Menu do terminal
- livros.py: Gerenciamento de livros
- usuarios.py: Gerenciamento de usuários
- emprestimos.py: Empréstimos
- relatorios.py: Devoluções e estatísticas
- consultas.py: Buscas no acervo
- validacoes.py: Validação de entradas
